# 🕵️ Dorex

**Dorex** — это консольный OSINT-инструмент для сбора и анализа данных из открытых источников. Разработан для аналитиков, исследователей и всех, кто ценит информацию.

> **Текущий статус:** Версия 1.4 в разработке. Версия 1.3 доступна для скачивания.

---

## 🚀 Основные возможности

*   **Поиск по номеру телефона:** Определение страны, оператора и региона по DEF-коду.
*   **Поиск по email:** Проверка валидности, генерация дорк-запросов.
*   **Поиск по никнейму:** Проверка существования аккаунтов на различных платформах.
*   **Поиск по IP:** Определение провайдера, геолокации и репутации адреса.
*   **Поиск по Telegram:** Анализ публичных аккаунтов.
*   **Шифрование текста:** Быстрое шифрование данных прямо в консоли.
*   **Генераторы:** Создание паролей, тестовых личностей, email, IP и MAC-адресов (только для легальных целей).
*   **OSINT-инструменты:** Встроенный сборник полезных сервисов.
*   **Визуализация данных:** Модуль для визуализации связей (в разработке).
*   **Заметки:** Ведение локальных записей для расследований.

## 🛠 Технологии

*   **Язык:** Python 3
*   **Библиотеки:** `requests`, `os`, `platform`, `subprocess`, `colorama` и другие.
*   **Интерфейс:** Консольный (CLI).
